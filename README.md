# Modern Portfolio Website for Creative UI/UX Designer & Web Developer

A fully animated, modern portfolio website showcasing creative UI/UX design and web development skills with glassmorphism and neumorphism design elements.

## 🌟 Features

### Design & Visual Elements
- **Futuristic Color Palette**: Deep navy blue (#0F172A), soft purple (#8B5CF6), and white accents
- **Glassmorphism Effects**: Transparent elements with backdrop blur and subtle borders
- **Neumorphism Styling**: Soft inset/outset shadows creating depth and tactile feel
- **Custom Cursor**: Interactive cursor with following animation
- **Scroll Progress Indicator**: Visual progress bar showing scroll position

### Animations & Interactions
- **Smooth Scroll-based Animations**: Elements animate in as they enter viewport
- **Parallax Effects**: Floating elements move at different speeds during scroll
- **Hover Interactions**: Cards lift, rotate, and transform on hover
- **Stagger Animations**: Child elements animate in sequence
- **Morphing Blobs**: Fluid background animations in contact section
- **Floating Particles**: Animated particles in hero section
- **3D Transformations**: Skills icons and project cards with 3D effects

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools required - pure HTML, CSS, and JavaScript

### Installation
1. Download or clone the repository
2. Open `index.html` in your web browser
3. The website will load with all animations and effects

### File Structure
```
portfolio-website/
├── index.html          # Main HTML structure
├── styles.css          # All CSS styles and animations
├── script.js           # JavaScript functionality and interactions
└── README.md           # This documentation
```

## 🎨 Customization

### Color Palette
Update the CSS custom properties in `styles.css`:
```css
:root {
    --primary-navy: #0F172A;
    --accent-purple: #8B5CF6;
    --light-purple: #A78BFA;
    /* ... other colors */
}
```

### Content
- Update personal information in `index.html`
- Modify skills, projects, and testimonials
- Replace placeholder images and links
- Customize contact information

### Animations
- Adjust animation durations in CSS
- Modify JavaScript timing for different effects
- Add or remove animated elements as needed
